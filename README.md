#Arduino Smart Safe

Projeto de um cofre inteligente desenvolvido com Arduino no Tinkercad.

## Funcionalidades

- Sistema de senha numérica
- LED verde para acesso permitido
- LED vermelho para acesso negado
- Servo motor simulando abertura do cofre
- Alarme sonoro com buzzer

## Componentes Utilizados

- Arduino UNO
- Keypad 4x4
- Servo Motor
- LEDs
- Resistores
- Piezo Buzzer

## Tecnologias

- Arduino C++
- Tinkercad
- GitHub

## Objetivo

Projeto criado para estudo de Arduino, eletrônica e Internet das Coisas (IoT).
